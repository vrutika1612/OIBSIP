# GitHub Upload Guide

Use the existing OIBSIP repository. Do **not** create another repository.

```bash
git clone <MY_OIBSIP_REPOSITORY_URL>
cd OIBSIP
```

Copy this project folder into:

`Java-Task4-OnlineExaminationSystem/`

Then:
```bash
git add .
git commit -m "Add Task 4 Online Examination System"
git push origin main
```

If your repository uses another default branch, push to that branch instead.

## Verify
Open the existing OIBSIP repository on GitHub and confirm that `Java-Task4-OnlineExaminationSystem/` appears at the repository root and contains `pom.xml`, `README.md`, `src/`, `screenshots/`, and the guides.
